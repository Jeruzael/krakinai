# Bulk Style Selection for Storyboard Shots

**Date:** 2026-11-13  
**Status:** Approved

## Objective

Let a user select multiple storyboard shots, choose one shared Style library asset in the selection panel, and apply that style to each selected shot that has an eligible preferred Recipe. Each changed shot receives a new Recipe take with the chosen Style; its original takes remain available.

## User experience

- Add a **Style for selected shots** control to the existing project shot selection panel.
- The selector lists active library assets in the `styles` category. One selected Style is shared across all eligible shots.
- **Apply Style** opens a confirmation summary before writing. The summary shows how many shots will change, how many already use that exact Style revision, and how many cannot be changed (with counts by reason).
- Confirmation explains that new takes will become preferred, existing takes remain available, and no image or video is generated by this action.
- On success, refresh the storyboard and clear the selection as the other bulk actions do. On failure, preserve the selection and report the error.

## Eligibility and unchanged data

- A shot is eligible only when it has a current `selectedSceneId` that is also in its `takeSceneIds`, and that saved scene is a Recipe.
- The new take starts from that preferred Recipe only; the operation never guesses among unselected takes or creates placeholder recipe content.
- Replace only the Recipe's `style` slot with a snapshot of the selected Style asset. Preserve the other recipe slots, scene instructions, settings, dialogue, and source references.
- Reassemble the Recipe prompt outputs from the new Style snapshot and the preserved inputs.
- Leave the original saved scene and its media untouched. The new take is unreviewed and has no result media; its source scene remains available as the prior take. The project's production status is preserved.
- If the selected Recipe already has the chosen Style asset ID and revision, count it as unchanged and do not create another take.

## Safe exclusions

Report these selected shots as skipped, with a reason, and leave them untouched:

- No available preferred saved scene.
- The preferred scene is a Direct Prompt. Converting it to a Recipe is a separate guided action.
- The preferred Recipe contains Blocking, an ensemble, a keyframe plan, image prompt snapshots, manual image outputs, or manual output overrides that require their own review decisions.

The Style slot is optional across the current shot types, so eligible Recipes may receive the Style even if they had no Style slot before.

## Persistence and failure behavior

- Revalidate the selected shot IDs, chosen Style asset revision, current project revision, and each preferred source scene at write time.
- Create one distinct alternate Recipe take per changed shot, add it to that shot's takes, and select it as preferred.
- Commit all eligible takes and project references in one IndexedDB transaction. If validation or storage fails, abort the whole write so no selected shot is left partially updated. Deterministic exclusions do not block eligible shots from applying.
- Never edit, replace, delete, or regenerate an existing saved scene or its media.

## Acceptance criteria

1. Selecting multiple shots exposes one shared Style selector in the selection panel.
2. The confirmation summary accurately separates changed, unchanged, and skipped shots.
3. Applying a Style creates a distinct Recipe take for every eligible changed shot, with only the Style slot changed and regenerated prompt outputs.
4. Every created take becomes preferred for its own shot; every prior take and its media remain intact.
5. A storage or stale-project failure leaves all source scenes and project references unchanged.
6. Direct Prompts and advanced authored scenes are explicitly reported as skipped rather than silently altered.
7. The UI states that applying a Style does not generate image or video media.
